BRAND: AImpostor Syndrome  —  DIRECTION B (SOLID VIOLET)
Spelling is "impostor" (with an o). Canonical everywhere.

CONCEPT
  Mark = prompt (>) -> session waveform -> mic.
  Reads left-to-right as the pipeline: command in -> conversation -> published.

TYPE
  Display / UI : Space Grotesk (400/500/600/700)
  Code / labels: JetBrains Mono (400/500/700)
  Scale: Display 62/600 · H1 40/600 · H2 28/600 · Body 17/1.6
         Label mono 12, uppercase, 0.18em tracking · Code mono 14

COLOR
  Primary violet: #9B7CFF  (bright, mid — use everywhere the brand shows)
  Deep violet   : #7C5CF0  (violet text/links on light backgrounds — contrast)
  Neutrals: Ink #0D1017 · Surface #14181F · Slate #8A93A6 · Paper #F7F6F2 · White #FFFFFF

SOLID RULES  (the whole point of this direction)
  ONE flat brand color. No gradients anywhere — not on the mark, buttons,
  or headings. Primary buttons = #9B7CFF fill with #0D1017 text.
  Violet text on light must use the deeper #7C5CF0 for contrast.
  Depth comes from a faint violet radial glow on dark heroes, never a fade on the mark.

SHAPE
  Radius: avatar 34 · cards 14-16 · buttons 10 · pills 999
  Dark surfaces on Ink #0D1017; light surfaces on Paper #F7F6F2.

VOICE
  Wry, self-aware, engineering-in-public. "Ship every week. Publish before perfect."
