# Website direction — Gradient

A self-contained jump-off bundle for building **one of two** website versions. Hand this whole
folder to Claude Design to build a full website in the **Gradient** brand direction.

## The direction

Vibrant, multi-color. A violet → pink → coral gradient runs through the identity.

| Role | Hex |
|---|---|
| Violet | `#8B5CF6` |
| Pink | `#E0559B` |
| Coral | `#FF6B5E` |
| Dark ground | `#0D1017` |
| Cream | `#F7F6F2` |
| Muted slate | `#8A93A6` |

Gradients are load-bearing here (violet→pink→coral across heroes and marks) — that's what
distinguishes this option from Solid Violet.

## What's in here

- `project/Handoff - Gradient.dc.html` — the primary design to build. Read it top to bottom.
- `project/AImpostor Marks.dc.html` — the logo/mark studies.
- `project/assets/` + `project/uploads/` — avatar, banner, lockup, logo.

## The handoff

Paste the design brief from
[`../../specs/1a-github-pages.md`](../../specs/1a-github-pages.md) into Claude Design along with
this bundle, and have it build the homepage (and episode-template feel) in this direction.
