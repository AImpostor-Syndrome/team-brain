# Website direction — Solid Violet

A self-contained jump-off bundle for building **one of two** website versions. Hand this whole
folder to Claude Design to build a full website in the **Solid Violet** brand direction.

## The direction

Restrained, single-color. One confident violet carries the identity; almost no gradients.

| Role | Hex |
|---|---|
| Violet (primary) | `#9B7CFF` |
| Violet (deep) | `#7C5CF0` |
| Dark ground | `#0D1017` |
| Panel | `#14181F` |
| Cream | `#F7F6F2` |
| Muted slate | `#8A93A6` |

The point of difference from Gradient: this direction commits to a single violet and stays
clean, rather than running a multi-color gradient.

## What's in here

- `project/Handoff - Solid Violet.dc.html` — the primary design to build. Read it top to bottom.
- `project/AImpostor Marks.dc.html` — the logo/mark studies.
- `project/assets/` + `project/uploads/` — avatar, banner, lockup, logo.

## The handoff

Paste the design brief from
[`../../specs/1a-github-pages.md`](../../specs/1a-github-pages.md) into Claude Design along with
this bundle, and have it build the homepage (and episode-template feel) in this direction.
