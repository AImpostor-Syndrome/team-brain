# The project is AImpostor Syndrome — impostor with an "o"

## Context

By the second session the project was operating under three names at once:

- **IMPOSTRS.AI** — what this brain's README and project folder said.
- **AImposter-Syndrome** — the GitHub org, spelled with an *e*.
- **aimpostersyndrome.\*** — the domains we were about to buy, also with an *e*.

Nobody had decided; the names had accreted. That is cheap to fix on day two and expensive to
fix after the first video is public, because a name propagates into video descriptions, links,
and other people's bookmarks, and none of those get retroactively corrected.

Then we noticed the spelling was simply wrong. **"Impostor"** is the standard English spelling
and the one used in the psychological term *impostor syndrome*, which is the entire pun.
"Imposter" is a listed variant, but it is the minority spelling and it is not what the
phenomenon is called.

Checking the correct spelling turned up something better than the fallback: `aimpostorsyndrome.com`
was **available**, where the misspelled `.com` was already taken.

## Decision

The project is **AImpostor Syndrome**. One spelling, everywhere:

| | |
|---|---|
| Domain | `aimpostorsyndrome.com` |
| YouTube | `@aimpostorsyndrome` (brand account, not a personal channel) |
| GitHub org | `AImpostor-Syndrome` — renamed from `AImposter-Syndrome` |
| This brain | `projects/aimpostor-syndrome/` — renamed from `projects/impostrs-ai/` |

**IMPOSTRS.AI is retired.** It is not a codename, not an alias, not an internal name. Having a
second name for the same thing is the problem this decision exists to end.

## Why

The `.com` is the only genuinely scarce asset in the list. Registrars will always sell you
another `.online` or `.video`; there is exactly one `aimpostorsyndrome.com`, it was free, and
it renews at ~$15/yr rather than the $35–93/yr the alternative TLDs escalate to after their
first-year discount. Buying it settles the spelling permanently and cheaply.

Correct spelling over the variant, because the pun only lands if it's the word people actually
know. A show about impostor syndrome that misspells "impostor" is making the joke about itself
by accident.

One name over a public/internal split, because the split has a real cost and no benefit here.
Every agent reading this brain has to learn that IMPOSTRS.AI and AImpostor Syndrome are the
same thing, forever, and the only thing it buys is not doing a rename on day two.

The rename is cheap *now*. GitHub redirects renamed orgs, so old clone URLs keep working; the
brain is nine documents; nothing is published yet. In a month, with episodes live and links in
the wild, none of that is true.

## Rules out

- **The `imposter` spelling, with an "e."** It is a typo, not a variant we support. If you see
  it in a file, in a URL, or in a git remote, it is a leftover and should be fixed.
- **IMPOSTRS.AI as a name for anything.** Not the project, not the org, not a fallback handle.
- **Buying additional TLDs defensively** (`.online`, `.live`, `.video`, `.ai`). We considered
  it and declined: the `.com` is the one that matters, and the rest are an ongoing renewal bill
  for names nobody will type. Revisit only if someone actually squats one.
- **Registering the misspelled `.com` as a redirect.** It's already taken by someone else, so
  this isn't available even if we wanted it. Expect some lost traffic from the typo and accept
  it.

## What this cost

Two commits and a folder rename, on the day it was caught. Worth recording that number: it is
the argument for catching the next one just as early.
