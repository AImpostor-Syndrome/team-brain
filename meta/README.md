# Meta

The rules about this repo. Read before adding a new area or changing how the brain is
organized.

## Documents

| Document | What it covers |
|---|---|
| [`structure-spec.md`](structure-spec.md) | How the brain is organized and how an agent navigates it. **Provisional** — a real spec exists somewhere and should replace this. |

## The short version

Every folder has a README, and that README is an index with a one-line hook per entry. An
agent should never need to list a directory to know what's in it. Every document has
frontmatter and a title. Dates are absolute. Structure stays shallow — most answers are two
hops from root.
